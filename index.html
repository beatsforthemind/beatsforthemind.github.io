Wallace Personal · By Eric Anderson

A steadfast companion.

A local-first assistant that helps one person remember, plan, and make room for the work and life ahead.

Wallace runs on Eric’s Mac. It brings private memory and bounded, read-only connections to the AI clients Eric chooses for development, research, and personal planning.

01

A personal installation

Wallace Personal is a single-owner application for Eric Anderson. This website explains the application; it does not offer account sign-in or display private account data.

02

Read, remember, prepare

Google connections provide recent Inbox context and upcoming calendar availability. Wallace cannot send email, change labels, or edit calendar events through these connections.

03

Personal stays personal

Personal Google content is restricted to personal and private-owner sessions. Work-facing planning may reflect aggregate busy time without sharing appointment titles, messages, or source links.

Before Google consent

Know what you are granting.

Google’s read-only permissions are broader than the data Wallace currently collects. Gmail permission allows reading mail and settings; Wallace collects a bounded recent Inbox view. Calendar permission allows reading accessible calendars; Wallace initially monitors only the primary calendar.

Credentials remain in an encrypted local vault. Requested personal context can be shared with an AI provider during an active session. Review the Google data details and AI client disclosure before authorizing. You can revoke Google access at any time.
